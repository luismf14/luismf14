## Projetos planejados

Os projetos abaixo estão no meu planejamento e serão publicados em repositórios próprios, cada um com testes e instruções de execução.

**API REST de gerenciamento de tarefas.** Back-end com autenticação de usuários, operações de cadastro, consulta, atualização e remoção, testes automatizados e documentação dos endpoints.

**API de ranking online.** Serviço para cadastro de jogadores, registro de pontuações e consulta de classificação, projetado para ser consumido por aplicações externas.

**Encurtador de URLs.** Aplicação que gera links curtos, redireciona acessos e apresenta estatísticas de cliques.

**Controle de finanças pessoais.** Aplicação para registro de receitas e despesas por categoria, com relatórios e exportação de dados.
